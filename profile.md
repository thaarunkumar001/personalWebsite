## Copywriting Rules
- Avoid generic phrases like “passionate professional,” “innovative thinker,” or “empowering businesses.”
- Keep the copy specific and believable.
- Emphasize systems, workflows, platforms, automation, and technical growth.
- Make the website useful for recruiter scanning.
- Write in a concise and high-trust tone.

- Build as a single static HTML file

- Fully responsive
